# Практика PKIS 3

Набор работ по моделированию компонентов, процессов и развёртывания проекта
TripBuilder.

Материалы представлены в Markdown-формате с диаграммами и пояснениями.

## Содержимое

- моделирование компонентов;
- жизненный цикл сущностей;
- процессы TripBuilder;
- комплексное моделирование поведения;
- моделирование развёртывания.

## Просмотр

Откройте Markdown-файлы в редакторе с поддержкой Mermaid. Исходный проект для
заданий находится в отдельной группе репозиториев TripBuilder.
